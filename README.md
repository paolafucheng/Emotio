# Emotio
Bienvenido/a a Emotio, una aplicación para registrar emociones y realizar otras actividades para trabajar la inteligencia emocional. Es un proyecto dentro de la asignatura de Lenguajes de Marca y Sistemas de Gestión de la Información, para el Grado Superior de Desarrollo de Aplicaciones Web (DAW).
